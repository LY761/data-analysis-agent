# 三条黄金演示

## 1. 确定性商品诊断

1. 使用 `scripts/import_olist_demo.py` 导入真实 Olist 数据。
2. 调用 `POST /api/diagnostics/products`。
3. 展示商品画像、SKU 下钻、规则标签、排名和下滑贡献。
4. 打开指标公式、版本和快照证据，强调 LLM 不参与数字计算。

## 2. Agent 自然语言问数

1. 在 Web 输入销售、库存或退款问题。
2. 展示规则快路由、必要澄清、Schema 检索和只读 SQL。
3. 展示 SQL 安全闸门、查询结果、图表和自然语言解释。
4. 使用危险 SQL 样例演示越权拦截，并展示模型失败降级。

## 3. 低库存任务工作流

1. 调用 `POST /api/workflows/low_stock_task/run`，提供快照和幂等键。
2. 查看商品诊断、低库存筛选、任务创建三个固定步骤。
3. 使用相同幂等键再次触发，展示运行去重。
4. 使用不同幂等键但相同业务快照触发，展示任务去重与审计记录。

## 评测说明

运行 `python scripts/run_agent_eval.py` 生成内部评测 JSON。简历只引用实际报告中的准确率、延迟和安全拦截结果；Token 未统一采集前保持“未测量”，不填写估算值。
