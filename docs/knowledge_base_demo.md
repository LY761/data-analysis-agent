## 一、公司简介

- 泛翼时代（FanYi Era）是一家跨境电商企业，主营 3C 数码配件：充电器、数据线、移动电源、蓝牙耳机。
- 主要销售渠道：亚马逊（美国站）、京东自营、品牌独立站。
- 品牌定位：中端性价比，主打"快充 + 续航"两大卖点。
- 目标市场：北美（60%）、欧洲（25%）、国内（15%）。

## 二、核心产品线

| 产品线 | 价格带 | 目标客群 | 主打卖点 |
|--------|--------|----------|----------|
| 快充充电器 | $15-30 | 通勤白领 | GaN 氮化镓、多口快充 |
| 移动电源 | $20-45 | 差旅人群 | 大容量、双向快充 |
| 数据线 | $8-20 | 学生/大众 | 编织线材、认证芯片 |
| 蓝牙耳机 | $25-50 | 年轻人 | 长续航、低延迟 |

## 三、定价与毛利

- 新品定价原则：毛利率不低于 **40%**（亚马逊 FBA 后）。
- 成本构成：采购成本 + 头程物流 + FBA 仓储配送费 + 平台佣金（约 15%）+ 广告费。
- 广告红线：ACOS 不高于 **25%**；新品测试期 2 周内允许最高 35%。
- 调价规则：周销 > 100 单的 SKU 不提价；库龄超 120 天的产品降价 15% 清库存。

## 四、供应商准入政策

- 注册资本不低于 **100 万元**。
- 必须提供 **ISO9001 质量体系认证**；充电类产品需 UL/CE 认证。
- 交货周期不超过 **30 天**；首批到货合格率不低于 98%。
- 每年度对供应商降本要求 ≥ **3%**；连续两季度交付评分低于 80 分启动更换流程。

## 五、物流与库存

- 亚马逊 FBA 头程：海运 30-40 天，空运 10-15 天。
- 京东自营：下单后 7 天内完成入仓。
- 补货红线：核心 SKU 可售库存低于 **30 天销量** 时触发补货计划。
- 安全库存：旺季（Q4）按 2.5 倍日均销量备货。

## 六、客户服务与售后

- 亚马逊 A-to-Z 索赔：**24 小时内**响应并处理。
- 退款红线：产品退货率超过 **8%** 必须下架复盘。
- 差评处理：24 小时内回复买家；目标好评率 ≥ **92%**。
- 国内售后：京东 7 天无理由退货，15 天质量问题换新。

## 七、平台运营规则

- 亚马逊 Listing 优化：标题 ≤ 200 字符，五点描述覆盖 3 个核心卖点 + 2 个差异化。
- 大促备货：京东 618 与双 11 提前 45 天锁定供应商产能。
- 竞品监控：每周跟踪 Top10 竞品的价格与评分，价格波动超 5% 需 48 小时内响应。
- 图片要求：主图白底，附图 ≥ 5 张（含尺寸对比、场景图、细节图）。

## 八、选品与上新流程

- 每月第一个周一召开选品评审会。
- 新品立项标准：竞品差评中可改进的痛点 ≥ **3 个**，且市场单价带毛利 ≥ 40%。
- 上新流程：选品 → 打样 → 供应商比价（≥3 家）→ 上架 → 广告测试 2 周 → 评审是否放量。
- 淘汰规则：上架 90 天后日均销量低于 5 单的产品进入清仓计划。

## 九、数据指标口径（重要）

- **销售额** = 订单实付金额（不含运费、税费、退款）。
- **毛利** = 销售额 - 采购成本 - 头程物流 - 平台佣金 - FBA 费用。
- **毛利率** = 毛利 / 销售额。
- **退款率** = 退款订单数 / 总订单数。
- **动销率** = 近 30 天有销量的 SKU 数 / 在售 SKU 总数。
- **库存周转天数** = 期末库存金额 / 日均销售成本。
- **ACOS** = 广告花费 / 广告带来的销售额。

## 十、组织与联系方式

- 选品与采购：采购部（每周二供应商报价会）。
- 运营：亚马逊运营组 / 京东运营组，双周复盘会。
- 财务：每月 5 日前出具上月毛利报表。
